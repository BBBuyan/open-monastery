# Demo sign-in assets

The provider buttons use the product owner's trusted files directly from public:

- `google_g_logo.svg`
- `facebook_icon.svg`

Both are displayed unchanged using regular image elements. The button background,
border, and text use the app's theme colors. No theme-specific logo files or inline
SVG component are needed. Yahoo is no longer offered as a sign-in option.

These trademarks belong to their respective owners. Buttons provide local demo
selection only, without OAuth, provider SDKs, redirects, or credential collection.
