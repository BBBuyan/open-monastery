## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout. See `docs/agents/domain.md`.

### Product context

Before changing frontend copy, catalog presentation, prayer-request flows, or domain terms, read `GLOSSARY.md` and `docs/product-context.md`.

### Swagger

When changing API routes, handler annotations, request DTOs, or response models, regenerate Swagger docs from `server/` using the command in `server/README.md` under “To generate swagger docs”. Include the generated changes in `server/docs/`.
